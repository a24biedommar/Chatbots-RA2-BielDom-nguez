# Data Model: TravelBuddy PWA

## Entities

### Route
Represents a saved itinerary generated by the AI.

| Field | Type | Description |
|-------|------|-------------|
| id | string (UUID) | Unique identifier |
| title | string | Name of the route (e.g., "Barcelona Afternoon") |
| timestamp | number | Unix timestamp of creation |
| waypoints | Waypoint[] | Ordered list of stops |
| weather | object | Weather snapshot at creation |
| location | object | Coordinates {lat, lng} of origin |

### Waypoint
A specific location or activity in a route.

| Field | Type | Description |
|-------|------|-------------|
| title | string | Name of the stop |
| description | string | Brief details or rationale |
| lat | number | Latitude |
| lng | number | Longitude |
| duration | string | Estimated time (e.g., "45m") |
| order | number | Sort position in the route |

### ChatSession
Stores message history for persistence and context.

| Field | Type | Description |
|-------|------|-------------|
| id | string (UUID) | Unique identifier |
| messages | Message[] | History of user and AI turns |
| routeId | string (optional) | ID of the route generated in this session |

### Message
A single turn in the chat.

| Field | Type | Description |
|-------|------|-------------|
| role | "user" \| "assistant" | Message sender |
| content | string | Text content |
| timestamp | number | Unix timestamp |

## Relationships
- **Route** contains 1 or more **Waypoints**.
- **ChatSession** may be linked to one **Route**.
- **IndexedDB** stores all `Route` and `ChatSession` objects locally.
